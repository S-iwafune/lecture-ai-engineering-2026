# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  - 素のLLMは「3レベル」の意味を直接知っていないため、一般論で説明したり「分からない」と答えたりすることが多い。
  - 正解は講座の用語集にあり、課題の難易度に応じて「基礎・実装・発展」の3段階である。
- 用語集の正しい意味と比べて気づいたこと：
  - 事前知識がないと、講座固有の用語や設計意図を確実に理解できない。
  - そのため、用語集や指示書を参照しながら、LLM の回答を検証する姿勢が重要である。
- 表示できたトークン数（入力 / 出力）：
  - `response.usage_metadata` を読み出し、入力トークン数と出力トークン数を `app/ask.py` で表示できるようにした。
  - 実行時には `[token] 入力: ... / 出力: ...` の形式で確認できる。

## 宿題

- 取り組んだレベル：実装
- やったこと：
  - `app/ask.py` にトークン数表示を追加した。
  - `--interactive` オプションを実装し、同じ会話セッション中に複数の質問を続けられるようにした。
  - `client.chats.create(...)` と `chat.send_message(...)` を使って会話履歴を保持した。
- 結果：
  - 1回の質問だけでなく、連続した対話で前提や文脈を引き継いだ回答ができるようになった。
  - どの質問でどれだけのトークンを使ったかも確認しやすくなった。
- 気づき・疑問：
  - LLM の回答は、入力の文脈と会話履歴に大きく左右される。
  - 無料枠ではトークン数やレート制限が制約になるので、少なくとも必要な文脈だけを渡す設計が重要になる。
